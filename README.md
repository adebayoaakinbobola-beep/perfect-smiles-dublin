# Perfect Smiles Dublin

A polished, responsive website concept for **Perfect Smiles Dental Surgery** in Dublin 1, Ireland. The project is designed to present the practice, its treatments, and its patient experience in a clear, modern, and approachable way.

## Live Demo

https://perfect-smiles-dublin.vercel.app

## Project Overview

Perfect Smiles Dublin is a front-end dental practice website focused on a professional patient experience and clear conversion paths. Visitors can explore treatments, learn about the practice, find contact and location information, read frequently asked questions, and submit a demonstration appointment enquiry.

> **Portfolio note:** This is a website concept/demonstration project. The appointment form is a demo and does not create a real booking.

## Key Features

- Responsive design for desktop and mobile devices
- Mobile navigation menu
- Treatment overview for general dentistry, implants, crowns & bridges, orthodontics, and routine care
- Practice and patient-experience sections
- Expandable FAQ section
- Click-to-call contact actions
- Appointment enquiry interface with form validation and success state
- Clinic address and location presentation
- Accessible navigation labels and descriptive image alternative text

## Tech Stack

- React
- TypeScript
- Vite
- CSS
- Tailwind CSS tooling
- Lucide React icons
- Vercel for deployment

## My Contribution

I developed and refined this dental website concept with an emphasis on responsive layout, clear content hierarchy, patient-friendly navigation, strong calls to action, and a professional visual presentation suitable for a modern dental practice.

## Project Goal

The goal of the project is to demonstrate how a dental practice website can make essential information easy to find while guiding prospective patients toward contacting the clinic or starting an appointment enquiry.

## Run Locally

```bash
git clone https://github.com/adebayoaakinbobola-beep/perfect-smiles-dublin.git
cd perfect-smiles-dublin
npm install
npm run dev
```

For a production build:

```bash
npm run build
```
